# PDFSign

macOS-приложение для просмотра PDF-документов и размещения на них изображений (штампов, подписей, печатей).

## Возможности

- Просмотр PDF-документов с непрерывной прокруткой
- Размещение изображений (штампов, подписей) на страницах PDF
- Многооконный режим — каждый документ открывается в отдельном окне
- Библиотека изображений в боковой панели с синхронизацией между окнами
- Комментарии к изображениям
- Поддержка 50+ языков интерфейса, включая RTL (арабский, иврит, персидский)
- Полная поддержка нативного меню macOS

## Интерфейс

### Экран приветствия (Welcome Screen)

Главное окно приложения при запуске:

- **Иконка приложения** в центре
- **Кнопка "Open PDF"** — открывает диалог выбора файла
- **Список недавних файлов** — до 12 последних открытых PDF
  - Клик по файлу открывает его в новом окне
  - Наведение показывает кнопку удаления из списка

При открытии PDF экран приветствия автоматически скрывается. При закрытии всех PDF-окон снова появляется.

### Окно просмотра PDF (PDF Viewer)

Основное рабочее окно:

```
┌─────────────────────────────────────────────────────────────────┐
│  [Toolbar: Share button]                                        │
├──────────────────────────────────────────────────┬──────────────┤
│                                                  │              │
│                                                  │   Sidebar    │
│               PDF Document                       │   (Images)   │
│               (continuous scroll)                │              │
│                                                  │              │
│         [Page 3 of 10] — page indicator          │              │
│                                                  │              │
├──────────────────────────────────────────────────┤              │
│  [−] [100%  ▼] [+]  — zoom controls              │              │
└──────────────────────────────────────────────────┴──────────────┘
```

**Компоненты:**

| Компонент | Описание |
|-----------|----------|
| Toolbar | Нативный тулбар macOS с кнопкой Share |
| PDF Area | Область просмотра PDF с непрерывной прокруткой |
| Page Indicator | Плавающий индикатор "Page X of Y", появляется при прокрутке |
| Zoom Controls | Кнопки −/+, выпадающий список масштаба |
| Sidebar | Боковая панель с библиотекой изображений |

### Окно настроек (Settings)

Фиксированный размер 650×500, не изменяется.

**Разделы:**

1. **Language (Язык)**
   - Поле поиска для фильтрации списка
   - "System Default" — использовать язык системы
   - Список всех поддерживаемых языков

2. **Units (Единицы измерения)**
   - Сантиметры (cm) — по умолчанию
   - Дюймы (inch)

## Боковая панель (Sidebar)

### Характеристики

| Параметр | Значение |
|----------|----------|
| Ширина по умолчанию | 200 px |
| Минимальная ширина | 150 px |
| Максимальная ширина | 400 px |
| Высота кнопки Add | 48 px |
| Изменение ширины | Перетаскивание левой границы (4 px) |

### Способы добавления изображений

| Способ | Описание |
|--------|----------|
| **Кнопка "Add"** | Внизу панели, открывает системный диалог выбора файлов (множественный выбор) |
| **Drag & Drop** | Перетащить файлы из Finder на панель |
| **Paste (⌘V)** | Вставить изображение из буфера обмена (PNG или JPEG) |
| **Из Photos** | Через диалог выбора файлов доступна Медиатека Фото macOS |

**Источники изображений:**
- Файлы из Finder
- Приложение Фото (Photos) — через диалог "Add" или drag & drop из Photos
- Буфер обмена — скопированные изображения из любых приложений (⌘V)
- Скриншоты — автоматически копируются в буфер (⌘⇧⌃4)

**Поддерживаемые форматы:** PNG, JPG, JPEG, GIF, WebP, BMP, TIFF, TIF

При перетаскивании файлов панель подсвечивается синей рамкой (2 px).

### Пустое состояние

Когда библиотека пуста, отображается:
- Иконка `add_photo_alternate_outlined` (48 px)
- Текст "Drop images here"
- Подсказка "or paste / click Add"

### Структура карточки изображения

```
┌────┬─────────────────────────┐
│ ⋮⋮ │  ┌───────────────────┐  │
│    │  │                   │  │
│grip│  │   🖼 thumbnail     │  │
│    │  │               [×] │ ← кнопка удаления (при наведении)
│    │  └───────────────────┘  │
│    │  Comment text...        │ ← поле комментария
└────┴─────────────────────────┘
```

| Элемент | Описание |
|---------|----------|
| **Grip (⋮⋮)** | Ручка для переупорядочивания, ширина 28 px, курсор grab |
| **Thumbnail** | Превью с сохранением пропорций, border-radius 6 px |
| **Кнопка [×]** | Удаление, появляется при наведении/выделении, 24×24 px |
| **Комментарий** | Текстовое поле высотой 20 px под превью |

### Внешний вид превью

| Состояние | Описание |
|-----------|----------|
| Обычное | Светлая рамка 1 px (dividerColor) |
| Выделенное | Синяя рамка 2 px (primary, 50% прозрачности) |
| При наведении на grip | Фон становится светлее, иконка ярче |

**Кнопка удаления:**
- Позиция: верхний правый угол (4 px отступ)
- Размер: 24×24 px
- Фон: чёрный с 60% прозрачностью
- Иконка: белый крестик 16 px

**Если файл не найден:** показывается иконка `broken_image_outlined` на сером фоне.

### Переупорядочивание

- Потянуть за ручку grip (⋮⋮) — перетащить карточку вверх/вниз
- При перетаскивании: карточка увеличивается на 2%, прозрачность 90%
- Порядок сохраняется в базе данных Isar

### Комментарии к изображениям

**Режим просмотра:**
- Отображает текст комментария (обрезается с `...`)
- Tooltip с полным текстом при наведении (через 500 мс)
- При наведении появляется подчёркивание
- Клик переводит в режим редактирования

**Режим редактирования:**
- Inline TextField, высота 20 px
- Placeholder: "Comment"
- **Enter** — сохранить и выйти
- **Escape** — отменить без сохранения
- Клик вне поля — сохранить и выйти

### Перетаскивание на PDF

**Drag от превью** (не от grip):
1. Потянуть превью изображения на область PDF
2. При перетаскивании оригинал становится полупрозрачным (30%)
3. Feedback: изображение максимум 150 px по большей стороне
4. Отпустить на нужной странице PDF

### Удаление изображения из библиотеки

| Способ | Действие |
|--------|----------|
| Кнопка [×] | Клик по кнопке при наведении |
| Delete/Backspace | При выделенном изображении в sidebar |

### Ограничения изображений

| Параметр | Значение |
|----------|----------|
| Максимальный размер файла | 100 MB |
| Максимальное разрешение | 4096×4096 px |

### Синхронизация между окнами

Библиотека изображений хранится в **базе данных Isar** и синхронизируется между всеми открытыми PDF-окнами в реальном времени через stream.

## Работа с размещёнными изображениями

### Выделение

Клик по изображению выделяет его.

**Внешний вид выделенного объекта:**

```
         ↻              ↻            ← Зоны вращения (снаружи углов)
           ┌──■──────■──┐
           │            │
           ■            ■            ← Боковые маркеры
           │            │
           └──■──────■──┘
         ↻              ↻
```

| Элемент | Описание |
|---------|----------|
| Рамка выделения | Синяя (#0066FF), толщина 2 px, прозрачность 50% |
| Угловые маркеры | Белые квадраты 10×10 px с синей рамкой 2 px |
| Боковые маркеры | Белые квадраты 10×10 px с синей рамкой 2 px |
| Зоны вращения | Невидимые области 20×20 px снаружи углов (отступ 4 px) |

**Эффект наведения:**
- При наведении на маркер его рамка становится ярче (прозрачность с 50% до 100%)
- При наведении на зону вращения появляется иконка изогнутой стрелки (дуга 45° с двумя наконечниками)

### Маркеры изменения размера

**Угловые маркеры (4 шт.):**
- Расположение: углы объекта (topLeft, topRight, bottomLeft, bottomRight)
- Визуальный размер: 10×10 px
- Область клика: 24×24 px (больше для удобства)
- Действие: **пропорциональное** изменение размера (соотношение сторон сохраняется)
- Курсор: диагональная стрелка, меняется в зависимости от угла поворота объекта

**Боковые маркеры (4 шт.):**
- Расположение: середины сторон объекта (top, bottom, left, right)
- Визуальный размер: 10×10 px
- Область клика: 20×20 px
- Действие: **непропорциональное** растягивание (только одна ось)
- Курсор: горизонтальная или вертикальная стрелка, зависит от поворота

**Минимальный размер объекта:** 20×20 px.

### Вращение

**Зоны вращения (4 шт.):**
- Расположение: снаружи каждого угла, по диагонали от объекта
- Отступ от угла: 4 px
- Размер зоны: 20×20 px
- Курсор: grab → grabbing при перетаскивании

**Иконка вращения:**
- Появляется при наведении на зону вращения
- Дуга 45° с двумя треугольными наконечниками на концах
- Цвет: синий (#0066FF), при наведении становится ярче
- Ориентация иконки поворачивается вместе с объектом

**Механика вращения:**
- Вращение вокруг центра объекта
- Угол определяется по положению курсора относительно центра
- Плавный переход через ±180°

### Перемещение

- Курсор при наведении на объект: grab
- Курсор при перетаскивании: grabbing
- При перетаскивании объект следует за курсором с учётом текущего угла поворота

### Отображение размеров

При выделении объекта показывается метка размеров:
- Позиция: под нижней (визуально) стороной объекта, с отступом 16 px
- Формат: `12.5 × 8.3 cm` или `4.9 × 3.3 inch`
- Единицы измерения берутся из настроек
- Метка поворачивается чтобы оставаться читаемой (не вверх ногами)
- Первое число — ширина вдоль текущей нижней стороны

### Удаление

- Выделите изображение
- Нажмите **Delete** или **Backspace**
- Если фокус на текстовом поле (например, комментарий) — клавиши работают для редактирования текста

## Многооконный режим

### Типы окон

| Тип | Описание |
|-----|----------|
| Welcome | Главное окно (ID "0"), может быть скрыто |
| PDF Viewer | Отдельное окно для каждого документа |
| Settings | Единственный экземпляр (singleton) |

### Поведение

- Каждый PDF открывается в отдельном окне
- При открытии файла, который уже открыт — фокус на существующее окно
- Настройки — всегда одно окно (повторный вызов фокусирует существующее)
- Закрытие последнего видимого окна завершает приложение

### Меню "Window"

- Показывает список всех открытых окон
- Галочка отмечает активное окно
- Клик переключает на выбранное окно

## Настройки

### Хранение

Настройки хранятся в **SharedPreferences** macOS:

| Ключ | Тип | Значения | По умолчанию |
|------|-----|----------|--------------|
| `locale_preference` | String | `'system'` или код локали (`'ru'`, `'en_US'`) | `'system'` |
| `size_unit_preference` | String | `'cm'` или `'inch'` | `'cm'` |
| `recent_files` | String (JSON) | Массив объектов RecentFile | `[]` |

### Расположение файла

```
~/Library/Preferences/com.example.pdfsign.plist
```

### Синхронизация между окнами

При изменении настроек (язык, единицы измерения) все открытые окна автоматически обновляются через механизм WindowBroadcast.

## Рабочие процессы

### Открытие PDF

**Через меню:**
1. File → Open (⌘O)
2. Выберите PDF в диалоге
3. Документ откроется в новом окне

**Через Finder:**
1. Дважды кликните на PDF-файл
2. Или перетащите файл на иконку приложения

**Через недавние:**
1. File → Open Recent → выберите файл
2. Или кликните по файлу на экране приветствия

### Размещение изображения

1. Откройте PDF-документ
2. Добавьте изображение в библиотеку (кнопка "+" или drag-and-drop)
3. Перетащите изображение из библиотеки на нужную страницу PDF
4. Настройте положение, размер и поворот
5. Сохраните документ (⌘S)

### Сохранение документа

**Сохранить (⌘S):**
- Перезаписывает исходный файл
- Если файл ещё не сохранялся — показывает диалог "Save As"

**Сохранить как (⇧⌘S):**
- Всегда показывает диалог выбора имени и места

**Сохранить все (⌥⌘S):**
- Сохраняет все открытые документы с несохранёнными изменениями

### Закрытие с несохранёнными изменениями

При закрытии документа с изменениями появляется диалог:
- **Save** — сохранить и закрыть
- **Don't Save** — закрыть без сохранения
- **Cancel** — отменить закрытие

При закрытии всех (⌥⌘W) или выходе (⌘Q):
- **Save All** — сохранить все и выполнить действие
- **Discard** — закрыть все без сохранения
- **Cancel** — отменить

### Отправка документа (Share)

Функция Share в тулбаре или меню File позволяет отправить PDF через системный механизм macOS.

**Алгоритм работы:**

1. **Если изображений не размещено:**
   - Отправляется оригинальный PDF-файл напрямую

2. **Если есть размещённые изображения:**
   - Создаётся временная копия PDF с встроенными изображениями
   - Временный файл сохраняется в системную директорию temp:
     ```
     /var/folders/.../T/{uuid}.pdf
     ```
   - Изображения внедряются в PDF с учётом позиции, размера и поворота
   - Отправляется временный файл
   - Через 5 секунд временный файл автоматически удаляется

**Технические детали:**
- Используется `Share.shareXFiles` из пакета `share_plus`
- Открывается нативный macOS Share picker
- Встраивание изображений выполняется через Syncfusion PDF
