# PDFSign

macOS-приложение для просмотра PDF-документов и размещения на них изображений (штампов, подписей, печатей).

## Возможности

- Просмотр PDF-документов с непрерывной прокруткой
- Размещение изображений (штампов, подписей) на страницах PDF
- Многооконный режим — каждый документ открывается в отдельном окне
- Библиотека изображений в боковой панели с синхронизацией между окнами
- Комментарии к изображениям
- Поддержка 50+ языков интерфейса, включая RTL (арабский, иврит, персидский)
- Полная поддержка нативного меню macOS

## Интерфейс

### Экран приветствия (Welcome Screen)

Главное окно приложения при запуске:

- **Иконка приложения** в центре
- **Кнопка "Open PDF"** — открывает диалог выбора файла
- **Список недавних файлов** — до 12 последних открытых PDF
  - Клик по файлу открывает его в новом окне
  - Наведение показывает кнопку удаления из списка

При открытии PDF экран приветствия автоматически скрывается. При закрытии всех PDF-окон снова появляется.

### Окно просмотра PDF (PDF Viewer)

Основное рабочее окно:

```
┌─────────────────────────────────────────────────────────────────┐
│  [Toolbar: Share button]                                        │
├──────────────────────────────────────────────────┬──────────────┤
│                                                  │              │
│                                                  │   Sidebar    │
│               PDF Document                       │   (Images)   │
│               (continuous scroll)                │              │
│                                                  │              │
│         [Page 3 of 10] — page indicator          │              │
│                                                  │              │
├──────────────────────────────────────────────────┤              │
│  [−] [100%  ▼] [+]  — zoom controls              │              │
└──────────────────────────────────────────────────┴──────────────┘
```

**Компоненты:**

| Компонент | Описание |
|-----------|----------|
| Toolbar | Нативный тулбар macOS с кнопкой Share |
| PDF Area | Область просмотра PDF с непрерывной прокруткой |
| Page Indicator | Плавающий индикатор "Page X of Y", появляется при прокрутке |
| Zoom Controls | Кнопки −/+, выпадающий список масштаба |
| Sidebar | Боковая панель с библиотекой изображений |

### Окно настроек (Settings)

Фиксированный размер 650×500, не изменяется.

**Разделы:**

1. **Language (Язык)**
   - Поле поиска для фильтрации списка
   - "System Default" — использовать язык системы
   - Список всех поддерживаемых языков

2. **Units (Единицы измерения)**
   - Сантиметры (cm) — по умолчанию
   - Дюймы (inch)

| Уровень | Масштаб |
|---------|---------|
| Fit Width | Подогнать по ширине окна |
| 50% | 0.5x |

| 200% | 2.0x |

## Работа с размещёнными изображениями

### Выделение

Клик по изображению выделяет его. Выделенное изображение обводится синей рамкой.

### Изменение размера

| Элемент управления | Действие |
|-------------------|----------|
| Угловые маркеры (4 шт.) | Пропорциональное изменение размера |
| Боковые маркеры (4 шт.) | Непропорциональное растягивание |

**Минимальный размер:** 20×20 px.

### Вращение

Зоны вращения расположены снаружи углов изображения. При наведении появляется иконка изогнутой стрелки.

- Перетаскивание в зоне вращения поворачивает изображение
- Вращение вокруг центра изображения

### Отображение размеров

При изменении размера показывается метка с текущими размерами:
- Формат: `12.5 × 8.3 cm` или `4.9 × 3.3 inch`
- Единицы измерения берутся из настроек

### Удаление

- Выделите изображение
- Нажмите **Delete** или **Backspace**

## Недавние файлы (Recent Files)

### Характеристики

| Параметр | Значение |
|----------|----------|
| Максимальное количество | 12 файлов |
| Сортировка | По дате последнего открытия (новые сверху) |
| Хранение | SharedPreferences |

### Управление

- **Меню File → Open Recent** — список недавних файлов
- **Clear Menu** — очистить весь список
- **Экран приветствия** — клик по файлу открывает его

При попытке открыть несуществующий файл показывается сообщение об ошибке, файл удаляется из списка.

## Многооконный режим

### Типы окон

| Тип | Описание |
|-----|----------|
| Welcome | Главное окно (ID "0"), может быть скрыто |
| PDF Viewer | Отдельное окно для каждого документа |
| Settings | Единственный экземпляр (singleton) |

### Поведение

- Каждый PDF открывается в отдельном окне
- При открытии файла, который уже открыт — фокус на существующее окно
- Настройки — всегда одно окно (повторный вызов фокусирует существующее)
- Закрытие последнего видимого окна завершает приложение

### Меню "Window"

- Показывает список всех открытых окон
- Галочка отмечает активное окно
- Клик переключает на выбранное окно

## Настройки

### Хранение

Настройки хранятся в **SharedPreferences** macOS:

| Ключ | Тип | Значения | По умолчанию |
|------|-----|----------|--------------|
| `locale_preference` | String | `'system'` или код локали (`'ru'`, `'en_US'`) | `'system'` |
| `size_unit_preference` | String | `'cm'` или `'inch'` | `'cm'` |
| `recent_files` | String (JSON) | Массив объектов RecentFile | `[]` |

### Расположение файла

```
~/Library/Preferences/com.example.pdfsign.plist
```

### Синхронизация между окнами

При изменении настроек (язык, единицы измерения) все открытые окна автоматически обновляются через механизм WindowBroadcast.

## Рабочие процессы

### Открытие PDF

**Через меню:**
1. File → Open (⌘O)
2. Выберите PDF в диалоге
3. Документ откроется в новом окне

**Через Finder:**
1. Дважды кликните на PDF-файл
2. Или перетащите файл на иконку приложения

**Через недавние:**
1. File → Open Recent → выберите файл
2. Или кликните по файлу на экране приветствия

### Размещение изображения

1. Откройте PDF-документ
2. Добавьте изображение в библиотеку (кнопка "+" или drag-and-drop)
3. Перетащите изображение из библиотеки на нужную страницу PDF
4. Настройте положение, размер и поворот
5. Сохраните документ (⌘S)

### Сохранение документа

**Сохранить (⌘S):**
- Перезаписывает исходный файл
- Если файл ещё не сохранялся — показывает диалог "Save As"

**Сохранить как (⇧⌘S):**
- Всегда показывает диалог выбора имени и места

**Сохранить все (⌥⌘S):**
- Сохраняет все открытые документы с несохранёнными изменениями

### Закрытие с несохранёнными изменениями

При закрытии документа с изменениями появляется диалог:
- **Save** — сохранить и закрыть
- **Don't Save** — закрыть без сохранения
- **Cancel** — отменить закрытие

При закрытии всех (⌥⌘W) или выходе (⌘Q):
- **Save All** — сохранить все и выполнить действие
- **Discard** — закрыть все без сохранения
- **Cancel** — отменить

## Планы на будущее

### Z-order (порядок наложения)

Возможность изменять порядок наложения размещённых изображений:
- Переместить на передний план
- Переместить на задний план
- Переместить вверх/вниз на один уровень

### Конвертация изображений в PDF

Возможность создавать PDF из набора изображений:
- Выбор нескольких изображений
- Настройка порядка страниц
- Экспорт в единый PDF-документ
